# OV7670 Camera Module Wiring Guide

This document describes how to connect the OV7670 camera module to the Raspberry Pi Pico (RP2040).

## Hardware Requirements

- Raspberry Pi Pico (RP2040)
- OV7670 Camera Module
- Jumper wires
- Breadboard (optional)
- 10kΩ pull-up resistors for I2C (2x) - may not be needed if your OV7670 breakout board has them

## Pin Connections

### Power Connections

| Raspberry Pi Pico | OV7670 Module | Description |
|-------------------|---------------|-------------|
| GND               | GND           | Ground |
| 3V3 (OUT)         | VCC (3.3V)    | Power supply - **IMPORTANT: OV7670 is 3.3V only!** |

⚠️ **WARNING**: Never connect the OV7670 to 5V! It will permanently damage the camera module. Always use 3.3V.

### I2C (SCCB) Connections

The OV7670 uses SCCB (Serial Camera Control Bus), which is I2C compatible.

| Raspberry Pi Pico | OV7670 Module | Pin Number | Description |
|-------------------|---------------|------------|-------------|
| GP4               | SDA/SIOD      | Pin 6      | I2C0 Data line - requires 10kΩ pull-up to 3.3V |
| GP21              | SCL/SIOC      | Pin 27     | I2C0 Clock line - requires 10kΩ pull-up to 3.3V |

**Note**: If your OV7670 breakout board doesn't have pull-up resistors, you must add 10kΩ resistors from SDA and SCL to 3.3V.

### Camera Control Pins

| Raspberry Pi Pico | OV7670 Module | Pin Number | Description |
|-------------------|---------------|------------|-------------|
| GP3               | XCLK          | Pin 5      | Master clock (generated by PWM, ~20.83 MHz) |
| GP17              | RESET/RST     | Pin 22     | Camera reset (active low) |
| GP16              | VSYNC         | Pin 21     | Vertical sync |
| GP15              | HREF/HSYNC    | Pin 20     | Horizontal reference |
| GP14              | PCLK          | Pin 19     | Pixel clock |

### Data Pins (D0-D7)

The camera data pins connect to consecutive GPIO pins for efficient PIO-based capture:

| Raspberry Pi Pico | OV7670 Module | Pin Number | Description |
|-------------------|---------------|------------|-------------|
| GP6               | D0            | Pin 9      | Data bit 0 |
| GP7               | D1            | Pin 10     | Data bit 1 |
| GP8               | D2            | Pin 11     | Data bit 2 |
| GP9               | D3            | Pin 12     | Data bit 3 |
| GP10              | D4            | Pin 14     | Data bit 4 |
| GP11              | D5            | Pin 15     | Data bit 5 |
| GP12              | D6            | Pin 17     | Data bit 6 |
| GP13              | D7            | Pin 18     | Data bit 7 |

## OV7670 Module Pinout

Standard OV7670 module pinout (18-pin variant):

```
OV7670 Module
┌──────────────┐
│ 1  GND       │
│ 2  3.3V      │
│ 3  SCL/SIOC  │
│ 4  SDA/SIOD  │
│ 5  VSYNC     │
│ 6  HREF      │
│ 7  PCLK      │
│ 8  XCLK      │
│ 9  D7        │
│10  D6        │
│11  D5        │
│12  D4        │
│13  D3        │
│14  D2        │
│15  D1        │
```

**Note**: Some OV7670 modules have different pinouts. Always check your specific module's datasheet!

## Configuration in Code

The pin configuration is defined in `src/main_camera.c`:

```c
static struct ov2640_config camera_config = {
    .sccb = i2c0,
    .pin_sioc = 21,           // I2C0 SCL
    .pin_siod = 4,            // I2C0 SDA
    .pin_resetb = 17,         // Camera reset
    .pin_xclk = 3,            // Master clock for camera
    .pin_vsync = 16,          // Vertical sync
    .pin_y2_pio_base = 6,     // D0-D7, PCLK, HREF base pin (D0 starts at GP6)
    .pio = pio0,
    .pio_sm = 0,
    .dma_channel = 0,
    .image_buf = frame_buffer,
    .image_buf_size = sizeof(frame_buffer)
};
```

## Important Notes

1. **Voltage Level**: OV7670 is a 3.3V device. Never connect to 5V!

2. **I2C Pull-ups**: The I2C/SCCB bus (SDA and SCL) require pull-up resistors. Many OV7670 breakout boards include these, but if yours doesn't, add 10kΩ resistors from SDA to 3.3V and SCL to 3.3V.

3. **Pin Order**: The data pins D0-D7 must be on consecutive GPIO pins starting at GP6 for the PIO program to work correctly.

4. **PWDN Pin**: If your module has a PWDN (power down) pin, connect it to GND to keep the camera active.

5. **Clock Generation**: The XCLK (master clock) is generated by the RP2040's PWM at approximately 20.83 MHz (125 MHz system clock divided by 6).

## Testing the Connection

After wiring everything up:

1. Build and flash the `camera_test` firmware
2. Connect the Pico to your computer via USB
3. The device should appear as a USB Video Class (UVC) camera
4. Use camera software (VLC, OBS, etc.) to view the video stream
5. Monitor the UART output (115200 baud) on GP0/GP1 for debug information

## Troubleshooting

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| Camera not detected | I2C connection issue | Check SDA/SCL wiring and pull-ups |
| No video output | Data pins not connected | Verify D0-D7 connections |
| Corrupted image | Pin order incorrect | Ensure D0-D7 are on consecutive GPIOs |
| Dark/no image | XCLK not working | Check GP3 PWM output with oscilloscope |
| Device not mounting | USB issue | Check USB cable and firmware |
